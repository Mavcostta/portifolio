# Portfólio — Maria Vitória

Portfólio profissional de **Maria Vitória Florêncio da Costa**, estudante de
Análise e Desenvolvimento de Sistemas e Estagiária de Engenharia de Dados.

O site apresenta minha experiência profissional, formação, cursos, competências
técnicas, projetos e serviços de desenvolvimento web. Meu foco atual é construir
uma carreira em Engenharia de Dados e criar landing pages, portfólios e sites
institucionais simples para profissionais e pequenos negócios.

## Serviços

- Landing pages responsivas
- Portfólios profissionais
- Sites institucionais de uma página

## Competências em desenvolvimento

- **Dados:** Databricks, SQL e Python
- **Cloud:** AWS Athena, S3 e Glue
- **Monitoramento e visualização:** Control-M e Tableau
- **Desenvolvimento:** HTML, CSS, JavaScript, GitHub e VS Code

## Tecnologias do portfólio

- HTML5 semântico
- CSS3 com layout bento, responsividade e animações acessíveis
- JavaScript para menu mobile e pequenas interações
